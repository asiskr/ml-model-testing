# DAY 15 — Precision, Recall, F1, Confusion Matrix

---

## Why Accuracy Alone is Not Enough

100 patients: 90 healthy, 10 cancer. Model says "no cancer" to everyone.
Accuracy = 90/100 = 90%. But all 10 cancer patients were missed — they go home and die.
Accuracy hides the problem. Precision, Recall, F1 expose it.

---

## Confusion Matrix

A 2x2 table showing 4 types of predictions:

```
                  Actually Positive    Actually Negative
Predicted Positive:     TP                  FP
Predicted Negative:     FN                  TN
```

- **TP (True Positive)** — model said YES, actually YES. Correct catch.
- **TN (True Negative)** — model said NO, actually NO. Correct skip.
- **FP (False Positive)** — model said YES, actually NO. False alarm.
- **FN (False Negative)** — model said NO, actually YES. Missed. Dangerous.

**True/False** = was the model right or wrong?
**Positive/Negative** = what did the model say?

---

## 4 Formulas

```
Accuracy  = (TP + TN) / (TP + TN + FP + FN)  → overall, how many correct?
Precision = TP / (TP + FP)                    → of predicted positive, how many actually correct?
Recall    = TP / (TP + FN)                    → of actual positive, how many did model catch?
F1        = 2 × P × R / (P + R)              → balanced score of precision and recall
```

---

## Precision vs Recall — When Each Matters

**Precision matters when False Positive is costly:**
- Spam filter — important email goes to spam = bad
- Court — innocent person convicted = very bad

**Recall matters when False Negative is costly:**
- Cancer detection — missing a cancer patient = fatal
- Airport security — missing a bomb = disaster
- Fraud detection — missing fraud = money lost

---

## Precision Definition
"Out of all predicted positive values, how many were actually correct?"

## Recall Definition
"Out of all actual positive values, how many did the model predict correctly?"

---

## F1 Score
Combines precision and recall into one number.
High only when BOTH are high. If either is low, F1 drops.

Example: Precision 99%, Recall 1% → Normal average = 50% (misleading). F1 = 1.98% (correct — model is useless).

---

## Code

```python
from sklearn.metrics import confusion_matrix, precision_score, recall_score, f1_score

cm = confusion_matrix(y_test, predictions)
precision = precision_score(y_test, predictions)
recall = recall_score(y_test, predictions)
f1 = f1_score(y_test, predictions)
```

All three take same parameters (actual, predicted) but apply different formulas internally.

---

## Imbalanced Data Proof

100 patients (90 healthy, 10 cancer). Model predicts everyone as healthy.
- Accuracy: 90% ← looks great
- Precision: 0% ← never said "cancer"
- Recall: 0% ← missed all cancer patients
- F1: 0% ← model is useless

## Interview Lines

- "Precision: out of all predicted positive values, how many were actually correct."
- "Recall: out of all actual positive values, how many did the model predict correctly."
- "In cancer detection, recall matters more — missing a patient is fatal. In spam filtering, precision matters more — losing an important email is harmful."
- "Accuracy alone is misleading on imbalanced data. A model predicting all negatives gets 90% accuracy but 0% recall."
- "A developer tests if the model works. A QA engineer tests where it breaks — unseen data, edge cases, imbalanced classes, adversarial inputs."
